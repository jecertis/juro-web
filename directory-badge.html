Directory badge

The directory badge, and what it does and doesn't mean.

The directory badge is a small image that links back to JuroCompliant's DPDP & GDPR Compliance Partner Directory. It does not assert that any firm is DPDP or GDPR compliant. Badge embeds are not currently available on this page for any firm name.

Preview

Two sizes are available. Both link to the same directory page.

Flat — 240×28
Card — 240×100
What this badge is not

The badge does not mean Juro has verified, ranked, or certified your firm's compliance work. It only shows that your firm has requested (or holds) a listing in the directory. See the directory page for the full disclosure.

Getting a badge

This page does not generate an embed snippet for a firm name you type in. That capability was removed: it let any visitor, including one with no relationship to Juro, produce a Juro-branded badge for a firm that was never validated against a real listing. Badge embeds are not currently available. Firms can still request a directory listing.

Frequently asked questions

Does the badge mean my firm is DPDP or GDPR compliant?

No. The badge only shows that a firm has requested a listing in JuroCompliant's DPDP & GDPR Compliance Partner Directory. Juro does not verify, rank, or certify any listed firm's compliance status or work quality.

Can I generate a badge for my firm on this page?

No. This page does not generate a badge for any firm name typed in — that would let anyone claim a Juro-branded badge without a real listing. Badge embeds are not currently available.

Haven't requested a listing yet? Visit the directory to submit your firm.
