Directory badge

Embed the directory badge on your firm's website.

Any firm that requests a listing in JuroCompliant's DPDP & GDPR Compliance Partner Directory can add a free badge to its own website. The badge is a small image that links back to the directory, and it is available as soon as you submit the listing form, even before the directory's public listings go live.

Preview

Two sizes are available. Both link to the same directory page.

Flat — 240×28
Card — 240×100
What this badge is not

The badge does not mean Juro has verified, ranked, or certified your firm's compliance work. It only shows that your firm has requested (or holds) a listing in the directory. See the directory page for the full disclosure.

Get your snippet

Type your firm name to generate a snippet with a tagged link, so we can tell which firm's badge sent a visit. Leave it blank to get a generic snippet and fill in your own slug later.

Used only to build the link tag below (your-firm-name) — nothing is submitted or stored.

Paste either snippet directly into your site's HTML. No script or widget is required. The link opens the directory page in a new tab and carries UTM parameters (utm_source=badge, utm_medium=referral, utm_campaign=dpdp_readiness_badge, and a per-firm utm_content) so badge referrals are distinguishable from other traffic.


    


    
    

      
Frequently asked questions

      

        

          Does the badge mean my firm is DPDP or GDPR compliant?
          

            
No. The badge only shows that your firm has requested a listing in JuroCompliant's DPDP & GDPR Compliance Partner Directory. Juro does not verify, rank, or certify any listed firm's compliance status or work quality.

          

        

        

          What does the badge link track?
          

            
The badge links back to the directory page with tagged UTM parameters, including a per-firm campaign tag, so Juro can see how many visits each firm's badge sends. The badge itself does not collect visitor personal data.

          

        

        

          Is the badge free, and do I need to be listed already to use it?
          

            
The badge is free. It is available to any firm that has requested a listing through the directory's "Get listed" form, even before the directory's public listings go live.
